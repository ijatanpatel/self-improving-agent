# Projects and tasks

## Views
Each project can be shown as a Board, a List or a Calendar on every plan. Timeline view, which shows tasks as bars on a schedule, is available on the Team plan and above. Task dependencies on the timeline ("this task waits for that task") are available on Business and Enterprise.

## Subtasks
Tasks can have subtasks, and subtasks can have their own subtasks, up to 3 levels deep. Progress on a parent task is calculated from its completed subtasks.

## Recurring tasks
Set a task to repeat daily, weekly, monthly or on a custom schedule from the due date picker. The next copy of the task is created when the current one is marked complete, so you never have a pile of open copies.

## Task IDs
Every task gets an ID such as ORB-123. The prefix can be changed per project in Project settings. Task IDs are used to link commits and pull requests from GitHub.

## Archiving and deleting projects
Archiving hides a project but keeps everything searchable and restorable. Deleting moves the project to Trash, where it stays for 30 days before it is permanently removed. Only Admins and the project's creator can delete a project.
