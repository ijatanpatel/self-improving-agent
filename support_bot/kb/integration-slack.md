# Slack integration

## Connecting Slack
An Admin connects Slack from Settings > Integrations > Slack and approves the permissions in Slack. Each project can then post updates to one or more Slack channels. On the Free plan you can connect a single Slack channel; paid plans have no limit.

## Creating tasks from Slack
Type /orbit create followed by the task name, for example /orbit create Update pricing page. The task is created in your default project, which you can change with /orbit settings.

## Link previews
When someone pastes an Orbitask task link in Slack, it unfurls into a preview with the task name, assignee, status and due date. Previews respect permissions: people who cannot see the task in Orbitask only see the link.

## Disconnecting
Admins can disconnect Slack from the same settings page. Existing messages stay in Slack, but no new updates are posted.
