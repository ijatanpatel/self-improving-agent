# Files and storage

## File size limits
The maximum size of a single file is 25 MB on Free, 250 MB on Team and 1 GB on Business and Enterprise.

## Storage per workspace
Each workspace has a total storage limit: 1 GB on Free, 100 GB on Team, 500 GB on Business and a custom amount on Enterprise. You can see how much you use in Settings > Billing > Usage.

## Previews
Images, PDFs and Microsoft Office documents can be previewed inside Orbitask without downloading them. Other file types can be downloaded.

## File versions
If you upload a file with the same name to the same task, it becomes a new version of that file instead of a separate file. The last 10 versions are kept.
